# Order Radar

Собирает фриланс-заказы с нескольких площадок, отсеивает мусор по ключевым словам
и присылает подходящие в Telegram. Работает на Cloudflare Workers + Supabase, платить не нужно.

**Статус на 31.08.2026: код написан и покрыт тестами, но НЕ развёрнут и НЕ проверен вживую.**
Первый живой прогон делаешь ты по шагам ниже — до этого считать, что бот работает, нельзя.

---

## Что он делает

Раз в 10 минут воркер обходит все включённые площадки, разбирает их ответы в общий формат,
считает каждому заказу балл по ключевым словам и записывает в Supabase.
Заказы, которых ещё не было в базе и у которых балл ≥ 3, уходят тебе в Telegram.

Дедупликация построена на уникальном индексе `(source_id, external_id)` в базе:
если заказ уже есть, вставка молча пропускается, и повторное уведомление не приходит.
Это надёжнее, чем «помнить последний ID», потому что переживает перезапуск воркера.

## Что внутри

```
config/sources.js      какие площадки опрашиваем (и честный статус проверки каждой)
config/keywords.js     ключевые слова, веса, стоп-слова, порог балла
src/index.js           точка входа воркера: cron, /health, /run, вебхук Telegram
src/collect.js         главный цикл: обойти источники → отфильтровать → сохранить → отправить
src/sources/*.js       адаптеры под RSS, Freelancehunt API и превью Telegram-каналов
src/db.js              обращение к Supabase через REST, без внешних библиотек
src/telegram.js        отправка сообщений и их форматирование
supabase/migrations/   SQL-схема
scripts/check-sources.mjs  живая проверка площадок без записи в базу
test/                  тесты парсеров и фильтра на фикстурах
```

## Установка: 8 шагов

Всё, что ниже, делается один раз. Термины объясняю по ходу.

### Шаг 1. Поставить инструменты

Нужен Node.js версии 20 или новее. Проверить:

```bash
node -v
```

Дальше в папке проекта:

```bash
npm install
```

### Шаг 2. Создать бота в Telegram

1. Открой Telegram, найди **@BotFather**.
2. Отправь `/newbot`, придумай имя и логин (логин должен заканчиваться на `bot`).
3. BotFather пришлёт **токен** вида `8123456789:AAH...`. Сохрани его — это `TELEGRAM_BOT_TOKEN`.

### Шаг 3. Узнать свой chat_id

`chat_id` — это номер твоего личного диалога, бот шлёт сообщения именно туда.

1. Напиши своему новому боту любое сообщение (например `привет`).
2. Открой в браузере, подставив свой токен:
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
3. Найди в ответе `"chat":{"id":123456789`. Это число — `TELEGRAM_CHAT_ID`.

### Шаг 4. Создать таблицы в Supabase

1. Зайди в проект Supabase → раздел **SQL Editor** → **New query**.
2. Скопируй туда целиком содержимое `supabase/migrations/0001_init.sql` и нажми **Run**.
3. Проверь: в **Table Editor** должны появиться таблицы `orders`, `settings`, `runs`.

Затем возьми ключи: **Project Settings → API**.
Нужны `Project URL` (это `SUPABASE_URL`) и ключ **service_role** (это `SUPABASE_SERVICE_KEY`).

> ⚠️ Это ключ полного доступа, он обходит все ограничения безопасности.
> Он не должен попасть ни в репозиторий, ни в браузер, ни в чат. Только в секреты Cloudflare.

### Шаг 5. Проверить площадки локально, до всякого деплоя

```bash
npm run check-sources
```

Скрипт сходит на каждую включённую площадку и напечатает, сколько заказов пришло
и сколько прошло фильтр. Ничего никуда не пишет и никому не шлёт.

Так ты увидишь **до деплоя**, реально ли там есть заказы под твои услуги.
Если какая-то площадка отдаёт ошибку или ноль подходящих заказов — выключи её
в `config/sources.js` (`enabled: false`), чтобы не тратить лимиты.

### Шаг 6. Выложить воркер

Cloudflare Worker — это маленькая программа, которая живёт на серверах Cloudflare
и запускается по расписанию. Бесплатного тарифа тут хватает с большим запасом.

```bash
npx wrangler login       # откроет браузер, войди в свой аккаунт Cloudflare
npx wrangler deploy
```

Wrangler напечатает адрес вида `https://order-radar.<твой-поддомен>.workers.dev`.
Сохрани его — он понадобится в шаге 8.

### Шаг 7. Заложить секреты

Секреты хранятся на стороне Cloudflare, а не в файлах. Каждая команда спросит значение:

```bash
npx wrangler secret put SUPABASE_URL
npx wrangler secret put SUPABASE_SERVICE_KEY
npx wrangler secret put TELEGRAM_BOT_TOKEN
npx wrangler secret put TELEGRAM_CHAT_ID
npx wrangler secret put TELEGRAM_WEBHOOK_SECRET   # придумай длинную случайную строку
npx wrangler secret put RUN_KEY                   # ещё одна случайная строка
```

Случайную строку удобно сгенерировать так:

```bash
node -e "console.log(require('crypto').randomBytes(24).toString('hex'))"
```

После добавления секретов задеплой ещё раз: `npx wrangler deploy`.

### Шаг 8. Подключить команды бота

Чтобы бот отвечал на `/stats` и `/last`, надо сказать Telegram, куда слать сообщения.
Подставь свои значения и открой ссылку в браузере:

```
https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://order-radar.<поддомен>.workers.dev/tg/<TELEGRAM_WEBHOOK_SECRET>
```

В ответе должно быть `"ok":true`.

## Проверка, что всё живо

1. `https://<адрес-воркера>/health` — должен вернуть `{"ok":true,...}`.
2. `https://<адрес-воркера>/run?key=<RUN_KEY>&dry=1` — сухой прогон: обойдёт площадки,
   покажет отчёт, но ничего не сохранит и не отправит.
3. `https://<адрес-воркера>/run?key=<RUN_KEY>` — настоящий прогон. В Telegram должны
   прийти первые заказы.
4. Напиши боту `/stats` — покажет, сколько найдено за сутки.

Если что-то молчит: `npx wrangler tail` показывает логи воркера в реальном времени.

## Команды бота

| Команда | Что делает |
|---|---|
| `/stats` | сколько заказов найдено за 24 часа, по площадкам |
| `/last` | последние 10 находок |
| `/sources` | какие площадки опрашиваются и насколько они проверены |
| `/pause` | остановить уведомления (сбор продолжается) |
| `/resume` | включить уведомления обратно |
| `/run` | опросить площадки прямо сейчас |

## Как настроить под себя

**Ключевые слова и порог** — `config/keywords.js`. Балл заказа складывается из весов
сработавших правил. Порог `MIN_SCORE = 3` означает: одного слова «python» (вес 1) мало,
а «1С» (вес 5) достаточно. Если приходит много лишнего — подними порог до 5.
Если приходит мало — опусти до 2 и добавь своих слов.

**Площадки** — `config/sources.js`. Добавить RSS-ленту можно одной строчкой:
`{ id: 'моё_имя', kind: 'rss', url: '...', label: '...', enabled: true, status: '...' }`.

**Частота опроса** — `wrangler.jsonc`, поле `crons`. `*/10 * * * *` — каждые 10 минут.
Cloudflare считает время в UTC, но для «каждые N минут» это неважно.

После любых правок: `npm test && npx wrangler deploy`.

## Ограничения, о которых надо знать честно

- **Upwork RSS отключён** с 20 августа 2024 года, публичного API для поиска заказов нет.
  Автоматически собирать оттуда без стороннего платного сервиса не получится.
- **Хабр Фриланс закрыт** 28 февраля 2025 года.
- **FL.ru** закрывает ленту в `robots.txt` для внешних читалок. Отвечает ли она воркеру —
  покажет `npm run check-sources`. Если нет, источник надо выключить.
- **Kwork** документированного API не имеет. Существуют неофициальные обёртки поверх
  мобильного API, но это серая зона по правилам площадки — в проект намеренно не включено.
- **Telegram-каналы** читаются через публичное превью `t.me/s/<канал>`. Работает только
  для открытых каналов, и многие каналы из «топ-подборок» давно мертвы — проверяй свежесть
  постов перед тем, как включать.

Разбор площадок целиком — в `docs/MARKETS.md`.
