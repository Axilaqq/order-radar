# Источники: второй заход, 06.09.2026

Задача от владельца: Freelancehunt из основных источников убрать (площадка украинская,
профильных объявлений единицы). Интересуют **Россия** и **Запад** — США, Канада,
Западная Европа.

Ниже — что проверено запросом, а не взято из обзоров.

---

## Отпало

| Кандидат | Что выяснилось |
|---|---|
| **hh.ru** | **Публичный API поиска вакансий закрыт с апреля 2026.** `GET /vacancies` без авторизации отдаёт 403. Доступ только проверенным работодателям и рекрутинговым сервисам, с модерацией заявки. Это был самый очевидный кандидат по России — его больше нет. |
| **FL.ru** | Лента отвечает воркеру HTTP 403. |
| **SpecPortal** | 10 открытых проектов, самый свежий от 14.07.2026. API нет. Площадка фактически стоит. |
| **Freelancer.com** | RSS отдаёт 20 последних проектов без категорий. Из 20 фильтр прошли 2, оба нецелевые. |
| **Remotive** | Закрыт в robots.txt для нашего инструмента проверки. Не проверялся дальше. |

## Подключено

Все четыре отвечают JSON или RSS **без авторизации**, проверено запросом:

| Источник | Регион | Что отдаёт |
|---|---|---|
| RemoteOK | Запад | JSON, ~25 свежих вакансий, `salary_min`/`salary_max` в USD |
| Jobicy | Запад | JSON, `annualSalaryMin`/`Max`, `jobGeo` (US/EU) |
| We Work Remotely | Запад | RSS, 15 последних по программированию |
| Arbeitnow | Европа | JSON, преимущественно Германия, поле `remote` |

**Важная оговорка.** Это доски **удалённой работы**, а не разовых заказов: найм на
постоянку или долгий контракт, другой цикл. И открытым остаётся вопрос получения
оплаты из РФ — пока он не решён, отклики на эти вакансии смысла не имеют.

## Workspace.ru — самый интересный по деньгам и самый неудобный технически

**Почему интересен.** 13 716 тендеров, есть категория «CRM, 1C, ПО, чат-боты,
администрирование», бюджеты **100 000 – 1 500 000 ₽**, публикации свежие. Это на
порядок выше Инфостарта, где медиана 10 000 ₽.

**Что проверено:**

- `/api/tenders/` — закрыт в robots.txt, содержимое не проверялось.
- `/rss/tenders/` — HTTP 404.
- `/tenders/rss/` — HTTP 403.
- `sitemap-tenders-public-items.xml` — **есть, но бесполезен**: 1000+ ссылок,
  **без `lastmod`** и без гарантии порядка. Понять «что появилось нового» нельзя.
- `/tenders/` — страница списка открывается, на ней видны 10 свежих тендеров
  с заголовком, бюджетом и датой.

**Что говорит robots.txt.** Запрещены `/tenders/?`, `/tenders/*/?` и несколько
подкатегорий. Сама `/tenders/` — не запрещена. То есть опрашивать страницу списка
без параметров правилами сайта не запрещено, а вот ходить по фильтрам и
пагинации — запрещено, и мы этого делать не будем.

**Чего не хватает для парсера.** Нужна исходная HTML-разметка страницы: имена
классов и структура карточки тендера. Инструменты проверки отдают текст, а не
разметку, поэтому написать разбор «по памяти» нельзя — получится код, который
никто не проверял. Разметку берём у владельца (Ctrl+U → сохранить), пишем адаптер
и тест на сохранённой странице как фикстуре.

**Не проверено:** пользовательское соглашение Workspace на предмет автоматического
сбора данных. robots.txt — не то же самое, что условия использования.

## Что по России остаётся неразобранным

- **Госзакупки (zakupki.gov.ru)** — простого REST нет, официальная интеграция идёт
  через SOAP и требует ЭЦП. Для участия нужен статус ИП или юрлица.
- **Telegram-каналы** — механика `t.me/s/<канал>` рабочая и уже реализована,
  не хватает живого профильного канала. Проверенные ранее каналы из «топ-подборок»
  оказались мёртвыми или нецелевыми.
- **Kwork** — документированного API нет, неофициальные обёртки — серая зона.
